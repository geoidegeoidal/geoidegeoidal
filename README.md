# Jorge Ulloa

**Geógrafo · análisis espacial · GIS y datos**  
Chile · [Portafolio personal](https://julloa.space)

Transformo datos territoriales y ambientales en mapas, análisis y herramientas que ayudan a entender mejor los lugares y las decisiones que los afectan. Trabajo entre SIG, automatización de datos, cartografía web y comunicación visual.

## En qué trabajo

- **Análisis espacial y SIG:** QGIS, Python, SQL y flujos reproducibles.
- **Cartografía web:** mapas interactivos y herramientas geográficas en el navegador.
- **Datos ambientales y públicos:** integración, validación y visualización de fuentes.
- **Docencia:** formación aplicada en GIS, análisis espacial e IA.

## Proyectos destacados

- [LUZ·RM](https://github.com/geoidegeoidal/luz-rm) — visor independiente para explorar interrupciones eléctricas y su distribución territorial en la Región Metropolitana.
- [Azimut](https://github.com/geoidegeoidal/azimut) — geocodificación y normalización de direcciones chilenas desde el navegador.
- [GeoCallejero CL](https://github.com/geoidegeoidal/geocallejero) — plugin de QGIS para geocodificar direcciones chilenas.
- [HuellaRETC](https://github.com/geoidegeoidal/retc-map) — exploración territorial de datos de residuos industriales.
- [Ferias Libres Chile](https://github.com/geoidegeoidal/ferias-chile) — mapa interactivo de ferias y datos abiertos.
- [Censo 2024](https://github.com/geoidegeoidal/censo_2024) — procesamiento y visualización territorial de datos censales.
- [Relato hora a hora del 11 de septiembre de 1973](https://github.com/geoidegeoidal/storytelling-11s) — cartografía y narración histórica.
